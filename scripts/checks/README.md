# Скриптове за проверка (по избор, за разработчик)

Изискват Python 3 и `pip install playwright` (+ `playwright install chromium`), както и `npm i -D axe-core` за axe.py.

- `e2e.py noconfig|ui` — функционални сценарии (форма, галерия, меню, езици). Сайтът трябва да работи на http://localhost:3000.
- `axe.py` — автоматична проверка за достъпност на всички страници.
