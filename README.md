# Вила Лавандула — уебсайт (първа версия)

Двуезичен сайт (BG/EN) по избраната концепция B „Природен бутиков уют“. Технологии: Next.js 16, TypeScript и Tailwind CSS 4. Съдържанието е събрано на едно място в `src/content/`.

Сайтът е готов за преглед на компютъра. **Не е публикуван.** Преди публикуване прегледайте [docs/PRE_PUBLICATION_CHECKLIST.md](docs/PRE_PUBLICATION_CHECKLIST.md).

## Стартиране на компютъра

Нужен е **Node.js 20.9 или по-нов** (препоръчва се LTS версия от https://nodejs.org).

**Най-лесно (Windows):** щракнете два пъти върху `start-local.bat`. Скриптът инсталира пакетите при първото стартиране, сглобява сайта и отваря http://localhost:3000.

**Ръчно (терминал в тази папка):**
```
npm install
npm run build
npm start
```
След това отворете http://localhost:3000. Адресът води към `/bg`, а английската версия е на `/en`.

За работа по кода с автоматично опресняване използвайте `npm run dev`.

Проверки: `npm run typecheck`, `npm run lint`, `npm run build`.

## Как се редактира съдържанието

Всичко, което собственикът обикновено сменя, е в `src/content/`. След промяна стартирайте отново (`npm run build` и `npm start`) или използвайте `npm run dev`.

| Какво | Файл |
|---|---|
| Телефон, имейл, местоположение, капацитет, площ, легла, правила, оценка в Booking, връзки към Booking/Facebook, данни за поверителност | `src/content/site.ts` |
| Всички текстове на български | `src/content/i18n/bg.ts` |
| Всички текстове на английски (същата структура) | `src/content/i18n/en.ts` |
| Снимки в галерията, категории, надписи, alt текстове, снимки на началната страница | `src/content/gallery.ts` |
| Адреси на страниците | `src/lib/routes.ts` |
| Цветове и шрифтове | `src/app/globals.css` (блок `@theme`) |

**Добавяне на снимка:** сложете JPG (до 2000 px) в `public/photos/` и добавете запис в `src/content/gallery.ts`: ширина и височина в пиксели, категория, описание на BG и EN. Сайтът сам създава оптимизирани размери. Ако категория остане без снимки, тя изчезва от филтъра.

**Смяна на текст:** сменяйте само текста между кавичките. Ако пропуснете ключ в `en.ts`, `npm run typecheck` ще покаже грешка.

**Факти и статус:** всяка стойност в `site.ts` има `status: "extracted"` (взета от Booking/Facebook) или `"confirmed"` (потвърдена от собственика). Капацитетът се налага като ограничение във формата едва когато стане `"confirmed"`.

## Запитвания

Формата **не е резервационна система**. Тя изпраща имейл до собственика. Има сървърна валидация на датите и полетата, скрито поле капан и проверка за прекалено бързо попълване срещу ботове, ограничение на честотата, защита от двойно изпращане и състояния за изпращане, успех и грешка.

Изпращането се включва с настройки в `.env.local`. Образец с имената на нужните настройки е в `.env.example`, без тайни стойности. Докато настройките липсват, формата казва честно, че онлайн изпращането не е активно, и предлага телефон и имейл. Не се показва фалшив успех.

Няма онлайн плащане, автоматично потвърждение или показване на свободни дати. Изборът на дати във формата е само част от запитването.

## Структура

```
src/app/            маршрути, layout, sitemap, robots, 404, server action за формата
src/components/     Header, Footer, мобилна лента, галерия и диалог за снимки, форма
src/views/          съдържанието на всяка страница
src/content/        данни и текстове (редактират се тук)
src/lib/            маршрути, валидация, изпращане на имейл, лимит на честотата
public/photos/      оптимизирани копия на избраните снимки (оригиналите са в materials/)
public/brand/       подготвени активи на логото (оригиналните PNG са в основната папка)
public/fonts/       Noto Serif (400/500) и Manrope (400/600), латиница и кирилица
docs/               регистър на снимките, списък преди публикуване, резултати от проверките
```

Шрифтовете се обслужват от самия сайт (SIL Open Font License). Manrope съдържа българските буквени форми (`locl`, BGR) и браузърът ги използва автоматично на българските страници (`lang="bg"`). Noto Serif няма отделни български форми и използва стандартните кирилски.
